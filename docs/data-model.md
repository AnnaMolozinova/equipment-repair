# Модель данных

## Словарь проекта

| Термин курса | Термин моей темы |
| :--- | :--- |
| Ticket | Заявка на ремонт |
| Site | Оборудование (агрегат) |
| User | Диспетчер / Инженер / Руководитель |

## Сущности и поля

### User (Пользователь)

| Поле | Тип | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| id | int | PK | Машинный идентификатор |
| login | string | | Логин |
| passwordHash | string | | Хеш пароля |
| fullName | string | | ФИО |
| role | string | | Диспетчер / Инженер / Руководитель |

### Equipment (Оборудование — справочник)

| Поле | Тип | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| id | int | PK | Машинный идентификатор |
| name | string | | Название агрегата |
| siteId | int | FK | Участок, где стоит |

### RepairRequest (Заявка на ремонт — главный объект)

| Поле | Тип | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| id | int | PK | Машинный идентификатор |
| number | string | | Человеческий номер (REP-001) |
| title | string | | Заголовок |
| description | string | | Описание проблемы |
| status | string | | New / InProgress / Closed / Cancelled |
| equipmentId | int | FK | Ссылка на Equipment |
| createdByUserId | int | FK | Кто создал (диспетчер) |
| assigneeUserId | int | FK, NULL | Кто назначен (инженер), может быть пустым |
| createdAt | datetime | | Когда создана |

## ER-связи

- Один Equipment — много RepairRequest.
- Один User (диспетчер) создаёт много RepairRequest.
- Один User (инженер) может быть назначен на много RepairRequest.
- У нового RepairRequest исполнитель может отсутствовать (assigneeUserId = NULL).

## Проверка 3НФ

Название оборудования хранится в сущности Equipment один раз. RepairRequest содержит внешний ключ equipmentId. При переименовании агрегата меняется одна строка, поэтому текст названия не дублируется в заявках.
