# Архитектура системы

## Схема из трёх узлов

Vue 3 + Vite             ASP.NET Core              PostgreSQL
localhost:5173  ───────► localhost:5000  ───────► обычно :5432
                  HTTP                    запросы к БД

**Пример запроса:** `POST /api/repair-requests` с телом `{ "title": "Насос не запускается", "equipmentId": 2, "description": "Гудит и встаёт" }`

## Пояснение

Клиент Vue рисует экран и отправляет HTTP-запросы. ASP.NET Core проверяет правила. PostgreSQL хранит данные.

Прямой стрелки от браузера к базе нет: иначе клиент получает доступ к данным и обходит серверные правила.

**Подпись:** это и есть архитектура web-ИС семестра.
